# Data Structures and Algorithms

This repository contains my coursework and programming exercises for the **Data Structures and Algorithms** course at the Faculty of Mathematics and Informatics, Sofia University.

The repository is organized by weeks and will be updated throughout the semester.

## Repository Structure

Each `Week N` folder contains the materials and exercises covered during that week, including:

- Lecture presentations and notes
- Practical exercises
- My solutions to programming tasks

## Technologies

- **Language:** C++17
- **Compiler:** GCC (MinGW)
- **Editor:** Visual Studio Code

## Topics

The course covers topics such as:

- Algorithm analysis and time complexity
- Recursion
- Searching and sorting algorithms
- Linear data structures
- Trees and graphs
- Other fundamental algorithms and data structures

## Notes

The solutions are part of my learning process and may be improved or updated as I progress through the course.
